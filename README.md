# Portfolio Step 11 — SEO, Accessibility & Production Optimization

Replace these files in your existing project:

- `index.html`
- `src/input.css`
- `js/main.js`
- `assets/icons/favicon.svg`

Do not replace your `package.json` or existing Tailwind installation.

After replacing the files:

```bat
npm run dev
```

Check the site, then stop dev mode with `Ctrl + C` and run:

```bat
npm run build
```

`css/output.css` will be regenerated/minified by Tailwind.

Deferred on purpose until the real assets/URLs are ready:

- Original profile photo
- Dompetku screenshots
- Final Dompetku repository URL
- Live demo URL
- `canonical`, `og:url`, and `og:image`
